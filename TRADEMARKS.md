# ProfitCtl Trademark Guidelines

This document explains how the ProfitCtl name and related marks should be used in open-source and go-to-market materials.

## Marks

ProfitCtl owns the ProfitCtl name and related product marks used for the project.

The MIT License covers source code and documentation. It does not grant trademark rights.

## Allowed Uses

You may use the ProfitCtl name to:

- refer truthfully to the open-source project
- link to the official repository
- describe compatibility with the CLI or scenario format
- identify forks, plugins, skills, examples, tutorials, or integrations that work with ProfitCtl

## Required Clarity

Do not imply that the ProfitCtl project endorses, sponsors, or maintains your fork, service, integration, or commercial offer unless the maintainers have explicitly agreed.

Good examples:

- "Scenario templates for ProfitCtl"
- "Compatible with ProfitCtl"
- "A fork of ProfitCtl"

Avoid examples:

- "Official ProfitCtl Cloud" unless it is operated by the ProfitCtl maintainers
- "ProfitCtl Enterprise" unless it is operated by the ProfitCtl maintainers
- logos, names, or domains that make a third-party project look like the official ProfitCtl project

## Website Footer

Public ProfitCtl pages should include a notice like:

```text
Copyright (c) 2026 ProfitCtl contributors. ProfitCtl and related marks are trademarks of the ProfitCtl project.
```

## Questions

For permission questions, contact the maintainers through the official project repository.
