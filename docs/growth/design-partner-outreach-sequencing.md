# Design-Partner Outreach Sequencing

This is the minimal contact sequence for getting a target from first touch to evaluated user.

## Sequence Goal

Move a target through:

`target` -> `qualified` -> `installed` -> `activated` -> `calibrated` -> `design partner`

## Stage 1: First Touch

Use one short message.

What to say:

- what `ProfitCtl` does
- why their question is a fit
- which benchmark pair maps to their decision
- what the next step is

Do not explain the full product.

## Stage 2: Follow-Up

If they reply, ask only the qualification questions needed to confirm fit.

Keep the follow-up to:

- what pricing or contract question they are making
- whether the issue is recurring, one-time, or mixed
- whether they can install the CLI or use Bun
- whether they can share real inputs

## Stage 3: Install Push

Once qualified, move them to one install path.

Preferred path:

- public install script

Fallback:

- Bun package install

If installation needs too much help, record that friction explicitly.

## Stage 4: Activation

Ask them to run exactly one compare command or use one benchmark pair.

Do not give them a feature tour.

The only objective is to learn whether the output changed a decision.

## Stage 5: Calibration

If they see value, ask for the minimum real inputs needed to calibrate their scenario.

Request only:

- current pricing shape
- free vs paid behavior
- monthly vs annual mix
- one recurring-cost assumption
- one success criterion

## Stage 6: Design-Partner Commitment

Ask for one follow-up loop with one success criterion.

Examples:

- reject or justify one pilot-heavy deal
- compare current packaging against one change
- confirm recurring-margin economics with the product and finance lead

## Message Order

Use this order unless the target is unusually warm:

1. positioning
2. qualification
3. install
4. activation
5. calibration
6. follow-up commitment

## What To Avoid

- long email sequences
- feature dumps
- bespoke consulting before installation
- asking for too many inputs at once
- turning a target into a manual support queue
