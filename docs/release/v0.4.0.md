# ProfitCtl v0.4.0 evaluator guide

Use the published `v0.4.0-rc.1` evaluator build and the public example files.
The walkthrough uses local calculations and requires no provider keys.

## New behavior

- `system inspect`: local Python/configuration evidence with provider signals,
  hashes and explicit discovery limits; generated trees and symlinks excluded.
- `system evaluate`: strict `profitctl.system/v1` workload/service model,
  provenance, missing-input acquisition plan, per-service costs and margins.
- `system compare`: propagate declared driver changes and show affected service
  costs, changed assumptions and calculation dependencies.
- `system receipts`: summarize a sanitized Condere UsageReceipt export; preserve
  unreported/uncertain costs and omit arbitrary metadata.
- Modal official-domain registry support for the existing opt-in assessment.

Existing `simulate`, `compare`, `detect`, `assess`, ledger and four MCP tools keep
their interfaces. Python source collection is local-only; paid discovery is not
implicitly expanded to send source. Default unversioned Go builds still say
`dev`; candidate builds use `-ldflags="-X main.version=v0.4.0-rc.1"`.

## Install and run the walkthrough

Follow the [pinned installation instructions](../INSTALL.md#pin-a-version).
The release has archives for macOS and Linux on amd64 and arm64, a Windows
amd64 ZIP, and a Bun tarball. The shell installer covers macOS and Linux.
The signed macOS arm64 archive was used for the walkthrough below.

Use the example files from the same tag as the installed binary. Run these
commands with `profitctl` on your PATH.

```bash
git clone --depth 1 --branch v0.4.0-rc.1 https://github.com/IntelIP/ProfitCtl.git
cd ProfitCtl
profitctl version
profitctl system evaluate examples/system/condere-synthetic-baseline.json
profitctl system compare examples/system/condere-synthetic-baseline.json examples/system/condere-synthetic-cheaper.json
profitctl system compare examples/system/condere-synthetic-baseline.json examples/system/condere-synthetic-adverse.json
profitctl system evaluate examples/system/condere-production.json
profitctl system receipts examples/system/condere-sanitized-receipts.json
```

The binary reports `profitctl v0.4.0-rc.1`. The synthetic baseline costs $191.50,
the cheaper case costs $141.50, and the adverse case costs $276.50. The adverse
comparison reports an $85 increase. These values describe the example inputs.

The production template returns `incomplete`, with 19 missing inputs, null
total and margin, and exit 1. The sanitized receipt sample reports a $0.02
known subtotal and a null total with exit 1 because some costs are unavailable.
Malformed input returns exit 2. Output failure returns exit 3.

For the MCP check, configure the [local stdio companion](../INSTALL.md) with
`profitctl mcp --workspace-root /absolute/path/to/local-qa`. Create that folder
inside the checkout and copy `examples/mix_profit.yml` to `local-qa/scenario.yml`.
Use `profitctl_validate_scenario` with `{"scenario_path":"scenario.yml"}` and
expect `passed`. Use `{"scenario_path":"../examples/mix_profit.yml"}` to confirm
the companion returns `path_escape_rejected` for a file outside its workspace.

Local candidate smoke against Condere `32e9ec5` inspected 203 files, including
`pyproject.toml`, `Dockerfile.agentos` and the assessment workflow; generated
`.next` and `.venv` entries were absent. The production template surfaced 19
missing inputs. No provider calls or spend were required.

## Compatibility and limitations

The new JSON contract is additive. Reject unsupported versions and unknown
fields instead of silently approximating. Known zero and missing are distinct.
Source discovery is suggestive, not live topology. Causal links and rates must be
reviewed; no automatic capacity, quality, tier or autoscaler prediction. Synthetic
fixtures prove arithmetic, not production savings. Real usage collection and
recording remain PCTL-26/27. System CLI commands are available to local agents;
the private four-tool MCP contract has not gained a new tool.

[Condere walkthrough](../../examples/system/README.md).
